# A3 Activity Report — QC Story template

For a **variation** problem (inconsistent, defective, unpredictable). If the problem is **flow** (slow, queued, over-processed), start with `waste-analysis-template.md` instead — and come back here for whatever variation the waste analysis exposes underneath.

One page. If it doesn't fit, the thinking isn't tight enough yet. Charts over prose, bullets over paragraphs, and it must be readable without the author present to explain it.

Header: **Title** (should say what the activity is about and catch interest) · Team/circle · Author · Date · Doc no. · Category (Q / C / D / S / M / E / other)

---

## 1. Theme selection — background and aim
- What problem, and why this one?
- Alignment with department/company policy.
- Selection evidence: Pareto or the evaluation matrix.

## 2-1. Current condition
- The measured baseline. **Charts, not sentences.**
- Stratification that revealed the characteristic.
- State n and the data period.

## 2-2. Target
- **What / how much / by when**, in numbers.
- Basis for the number (best observed case, benchmark, theoretical ideal).

## 3. Activity plan
- Gantt: eight steps × weeks/months, plan vs. actual.
- Owners named.

## 4. Factor analysis
- Ishikawa diagram, or why-tree with judgments.
- **The narrowing down**: which factors were shortlisted, and — critically — the *evidence* that confirmed or eliminated each.
- Conclusion: the true cause, with its verification.

## 5. Countermeasures
- Table: factor → countermeasure → owner → date.
- Distinguish primary (containment) from secondary (structural).
- Expected effect of each, in numbers.

## 6. Effect verification
- **The same chart as §2-1**, before/after.
- Result vs. target, in the same unit.
- Tangible / intangible / ripple effects.

## 7. Standardization and control
- Standard created or revised (name it).
- Control method: what is measured, how often, by whom, what triggers action.
- How the standard was instilled — training, mechanism, poka-yoke.

## 8. Residual issues and future plans
- What is still open on this theme.
- Horizontal deployment: who else should adopt this.
- What the next cycle will address.

---

**Self-check before you publish:**
- Did you use the actual data?
- Is every claim backed by a chart or a number?
- Does the logic connect end to end — theme → characteristic → cause → countermeasure → result?
- Is the explanation minimal?
- Do the target and the result use the *same* characteristic value?
- Is it comprehensible without a verbal explanation?
