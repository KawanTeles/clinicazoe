# Processo obrigatório

Sempre execute nesta ordem:

1. Auditar toda a interface.
2. Encontrar inconsistências.
3. Criar plano de melhorias.
4. Implementar.
5. Revisar.
6. Validar responsividade.
7. Validar acessibilidade.
8. Validar performance.
9. Entregar relatório.
